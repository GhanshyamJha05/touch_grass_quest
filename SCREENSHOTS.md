# Screenshots Checklist for Blog Post

To make the blog post compelling, capture these exact moments during testing:

- [ ] **The Daily Task Shown**: A screenshot of the mobile UI on first load. It should show the large header, the streak counter (e.g., "Streak: 3 🔥"), the current task ("Find something with a spiral in it"), and the prominent "Take Photo" button.
- [ ] **A Clear Pass**: A screenshot of the UI right after uploading a valid photo. It should show the success text in green (e.g., "Pass! Clear shot of a snail shell outside.").
- [ ] **A Clear Fail**: A screenshot of the UI after uploading an invalid photo. The text should read something like "Not quite. This is a picture of a coffee mug, not a spiral."
- [ ] **The Screen-Photo Rejection**: A crucial screenshot demonstrating the prompt's robustness. The UI should show the gentle rejection message: "Looks like it's indoors or a screen, take it outside. I can see the laptop bezels."
- [ ] **The Done State**: A screenshot of the calm, minimal "Done for today. Go touch more grass. See you tomorrow!" screen that replaces the task UI after a successful submission.
